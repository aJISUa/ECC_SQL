# 6장 연습문제

1. 테이블을 작성하는 명령은? (CREATE TABLE, ALTER TABLE, CREATE VIEW)
   - 답: CREATE TABLE
   - ALTER TABLE은 변경, CREATE VIEW는 뷰 작성

2. 저장공간을 거의 쓰지 않는 객체는? (테이블, 인덱스, 뷰)
   - 답: 뷰
   - 저장되는 건 SELECT 명령뿐임

3. 인덱스의 효과는? (쿼리의 성능 향상, 데이터 정합성, 용량 절약)
   - 답: 쿼리의 성능 향상
   - 정합성은 제약이 담당하고, 인덱스는 오히려 저장공간을 더 씀
